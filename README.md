## 👋 About me

I'm **Muni Rul**, a student developer building products around **navigation, 3D experiences, and practical campus technology**.

Right now, my main project is **WayCampus** — a campus navigation platform combining search, route graphs, 360° panorama navigation, QR positioning, and a growing administrative layer.

> **My approach:** build something useful, test it in the real world, then improve it.

---

## 🚀 What I'm building

### 🧭 WayCampus
**Smart indoor campus navigation**

- Search buildings, rooms, and campus destinations
- Graph-based route guidance
- Linked 360° panorama navigation
- QR landmark positioning
- Campus directory and faculty workflows
- Mobile-first PWA experience
- Future direction: **markerless AR wayfinding**

[**Open WayCampus →**](https://campnav-b3om.onrender.com)
