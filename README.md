## ⚙️ My build loop

```mermaid
flowchart LR
    A([💡 Idea]) --> B([🔍 Explore])
    B --> C([🧪 Prototype])
    C --> D([🛠️ Build])
    D --> E([📍 Real-world test])
    E --> F([🚀 Ship])
    F -. learn .-> A
    AI{{🤖 AI copilot}} -.-> B
    AI -.-> C
    AI -.-> D
```

I don't treat AI output as the product. **The product is the working system that survives testing.**
